Регистр флага
	5 - Вызов получен, ждём 0 50 мкС
	6 - 0 50 мкС получен, ждём  бит
	
	
Прерывание по смене фронта:
	PUSH R16
	IN R16, SREG
	PUSH R16
	
	чтение и сброс таймера
	Если бит приёмника = 1 -> переходы по флагу
	Сравнение таймера, если <0,8 мС -> переходы по флагу
						>1,2 мС -> Выход по ошибке
						Иначе Бит 5 = 1 ; Сброс флагов, счетчиков, (LDI Flag, 1<<5), сброс регистра данных, выход из прерывания
	
	переходы по флагу:
	Если Флаг == 0 -> выход из прерывания
		Если бит 6 == 1 -> *6*
		Если бит 5 == 1 -> *5*

*5* Если бит приёмника = 0 -> Выход по ошибке, Иначе сравнение таймера:
					если <45 мкС -> Выход по ошибке
					если >55 мкС -> Выход по ошибке
					иначе Бит 6 = 1 (ORI Flag, 1<<6); выход из прерывания

*6* Если бит приёмника = 1 -> Выход по ошибке, Иначе сравнение таймера:
						если <21 мкС -> Выход по ошибке
						если <29 мкС -> счетчик++ (INC Flag), LSL Data, Сброс Бита "6" ANDI Flag, ~(1<<6), Проверка получения байта		(Получен бит 0)
						если <65 мкС -> Выход по ошибке
						если >75 мкС -> Выход по ошибке
						иначе -> счетчик++ (INC Flag), LSL Data, INC Data, Сброс Бита "6" ANDI Flag, ~(1<<6), Проверка получения байта		(Получен бит 1)
						
		Выход по ошибке: сброс флагов, счетчика, (CLR Flag), выход из прерывания
			
		Проверка получения байта: MOV R16, Flag
									ANDI R16, 0x0F
								Если  < 8 ->  выход из прерывания
								Иначе Бит 7 = 1, сброс флагов 0 и 1, счетчика (LDI Flag, 1<<7), выход из прерывания
								
		Выход из прерывания:	POP R16
								OUT SREG, R16
								POP R16
								RETI
